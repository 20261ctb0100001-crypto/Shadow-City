# Truck Simulator BR — Estradas do Brasil

O jogo publicado no GitHub Pages foi substituído por um protótipo original de condução de caminhão e entrega de cargas, com foco em controles para celular.

## Jogar

https://20261ctb0100001-crypto.github.io/Shadow-City/

## O que existe na versão publicada
- Caminhão-trator vermelho com semirreboque e rodas.
- Estrada longa, faixa central, paisagem rural, árvores e construções.
- Posto de combustível como destino da primeira entrega.
- Missão com marcador visual e mensagem de conclusão.
- Painel de velocidade, marcha e combustível.
- Joystick virtual, acelerador e freio para telas sensíveis ao toque.
- Teclado: WASD ou setas para dirigir; Espaço para frear; R para reiniciar.
- Câmera externa acompanhando o caminhão.

## Limitações atuais
Esta é uma primeira versão jogável de navegador, feita com modelos 3D procedurais e Three.js. Ainda não é um simulador completo: faltam física realista de carreta, colisões detalhadas, tráfego, outras rotas, cidades, sons, clima, postos funcionais e sistema de garagem. Os controles e a renderização foram verificados no navegador; a sensação de direção em diferentes celulares ainda precisa de testes.
